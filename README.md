# Date Reminder System

A modern web-based reminder and deadline management system built to help users track important dates, deadlines, renewals, and scheduled events. The system is designed for personal users, organizations, schools, offices, and businesses that need reliable date notifications and task reminders.
 ## Features
Add, edit, and delete reminders
Track upcoming deadlines and events
Dashboard with organized reminder list
Notification alerts for important dates
Responsive modern UI
Dark mode support
User profile menu
Search reminders quickly
Mobile-friendly navigation
## Tech Stack
### Frontend
Vue 3
Vite
Vue Router
Pinia
Axios
Tailwind CSS
### Backend
Laravel (API)
### Database
MySQL
